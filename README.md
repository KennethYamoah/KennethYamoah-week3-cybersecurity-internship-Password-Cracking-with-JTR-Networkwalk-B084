# Week 3 Cybersecurity Internship — Password Cracking with NetworkWalks

## Project Overview
This repository documents an authorized password-cracking laboratory exercise conducted as part of the Week 3 cybersecurity internship. A protected PDF was tested using candidate passwords, and the recovered password was verified by opening the document.

## Scope
- Password-protected PDF assessment
- Candidate password testing
- NetworkWalks password-cracking workflow
- Password verification
- Ethical reporting and evidence documentation

## Procedure Summary

1. Open the protected PDF `My-Locked-PDF1.pdf`.
2. Observe the **Document Open Password** prompt.
3. Supply candidate passwords to the NetworkWalks cracking workflow.
4. Continue until the successful match is found.
5. Record the recovered password.
6. Enter the recovered password in the PDF prompt.
7. Verify that the PDF opens successfully.
